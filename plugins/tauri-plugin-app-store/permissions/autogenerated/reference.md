## Default Permission

Read which channel installed this build (App Store, TestFlight sandbox, or Xcode), force a StoreKit sync, and show the offer-code redemption sheet

#### This default permission set includes the following:

- `allow-get-environment`
- `allow-sync`
- `allow-present-offer-code-redeem-sheet`
