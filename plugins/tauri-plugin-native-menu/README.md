# tauri-plugin-native-menu

The iPad's native menus, standing in for Tauri's menu plugin, which does not
exist on iOS:

- `set_menu` fills the iPadOS menu bar (`UIMainMenuSystem`, iPadOS 26+) with
  the desktop app menu's commands and their key equivalents, filed into the
  system's standard menus. Activations, clicked or typed, arrive on the
  `menuCommand` event. On iPadOS a main-menu key command claims its
  keystroke before the webview sees it, so the plugin also removes the
  system element groups whose shortcuts would shadow Reflect's (text
  formatting, Find, the Settings app link, the sidebar). Before iPadOS 26
  there is no menu bar, and `set_menu` installs nothing.
- `present_context_menu` shows a context menu at a point of the webview
  (`UIEditMenuInteraction`, iOS 16+) and resolves with the chosen item.

iOS-only: `apps/desktop/src-tauri` depends on this crate for the iOS target
and registers it under `#[cfg(target_os = "ios")]`. Android fails the build on
purpose (`src/mobile.rs`).

## Layers

| Layer | Path |
| --- | --- |
| Rust crate (command routing, desktop stub) | `src/` |
| Swift implementation | `ios/Sources/NativeMenuPlugin.swift` |
| TypeScript bindings | `packages/core/src/ipc/native-menu-plugin.ts` |
| Native menu host | `apps/desktop/src/services/ipad-native-menu.ts` |

The layout itself is the macOS app menu's (`apps/desktop/src/lib/native-menu/menu.ts`),
built from the command registry, so the menu bar, the ⌘K palette and the ⌘/
cheat sheet cannot drift apart.

## Changing the command surface

Adding, renaming, or removing a command or event must update, in the same PR:

1. `src/lib.rs` (`generate_handler!`), `src/commands.rs`, `src/models.rs`,
   `src/mobile.rs`, and the `src/desktop.rs` stub;
2. the Swift `@objc` method or `trigger` call in
   `ios/Sources/NativeMenuPlugin.swift`;
3. `build.rs` `COMMANDS` (then run a build once so
   `permissions/autogenerated/` regenerates, and commit the diff);
4. `permissions/default.toml`;
5. the capability mount in `apps/desktop/src-tauri/capabilities/ios.json`;
6. the TS binding in `packages/core/src/ipc/native-menu-plugin.ts`.
