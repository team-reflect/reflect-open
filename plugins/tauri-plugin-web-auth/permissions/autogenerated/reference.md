## Default Permission

Sign in to a web service through the system authentication session

#### This default permission set includes the following:

- `allow-start`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`web-auth:allow-start`

</td>
<td>

Enables the start command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`web-auth:deny-start`

</td>
<td>

Denies the start command without any pre-configured scope.

</td>
</tr>
</table>
