# Reflect Marketing Site — UI kit

A recreation of Reflect's "deep space" marketing homepage (`reflect.app`), composed
from the design system — the glassmorphic `space` Button variant and `Avatar`, on the
`.reflect-space` themed wrapper.

## Run
Open `index.html`. Loads `_ds_bundle.js` + `Site.jsx`, mounts `Site`.

## Fidelity notes
Copy is taken from the live site. The signature treatments — near-black `#030014`
canvas, top-center radial purple glow, glass hairline borders, and the inset-glow
`space` button — all come from the tokens. The real site has far more (meetings,
integrations, academy); this captures the core narrative and visual language.
